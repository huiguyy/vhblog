# 打开 OpenRouter 榜单，我差点以为排行榜坏了
![封面_OpenRouter国产霸榜](/images/718a61eb-a2da-4463-8c30-2366ce4449d3.png)


## 一个让人揉眼睛的画面

上周打开全球模型聚合平台 OpenRouter 的周度调用量榜单时，我盯着屏幕看了好几秒，确认自己没有开错网站。

前五名，全部是中国公司开发的模型。

DeepSeek V4 Flash 位居榜首，小米 MiMo V2.5、腾讯 Hy3、DeepSeek V4 Pro、智谱 GLM5.2 依次排开。没有 GPT，没有 Claude，没有 Gemini——这在此前任何一年的榜单上都不可想象。

这不是什么小样本的巧合。OpenRouter 是全球开发者调用大模型 API 最集中的入口之一，这张榜单背后是真实付费和真实流量的投票。就在一年前，榜单上还能打的国产模型只有 DeepSeek 和 Qwen 两家，如今却是一整排中国名字。
![插图_01_榜单冲击](/images/870fc543-6117-4f50-aa51-57dd303b08d0.png)


## 数字背后的历史性时刻

先看整体盘面。8 月 3 日至 8 月 9 日这一周，OpenRouter 全球大模型总调用量达到 69 万亿 Token，环比增长 21.48%。其中中国模型周调用量 34.25 万亿 Token，环比增长 21.76%；美国模型 9.17 万亿，虽然环比增长了 109.36%，但绝对量已经不在一个量级。

更值得注意的是：中国模型在 OpenRouter 上的调用量，已经连续 15 周超过美国。

领头羊 DeepSeek-V4-Flash-0731 单周调用量 8.83 万亿 Token，较前一周暴涨 570%。腾讯 Hy3 以 8.05 万亿紧随其后，环比增长 67%。前十名里中国模型占据六席，合计约 35.58 万亿 Token。

如果单独看某一天的数据，小米 MiMo-V2.5 甚至出现过单周 10.5 万亿 Token 的登顶表现，成为当周全球唯一突破 10 万亿的模型。
![插图_02_数据洪流](/images/9354ac61-21d9-40ac-8634-583e2e4d2616.png)


## 凭什么赢？三个关键词

国产模型霸榜的原因，拆开来无非三个词：开源、便宜、够用。

**开源**是最强的杠杆。《纽约时报》分析了 OpenRouter 上 800 万用户的数据后发现，中国开源模型占总使用量的比例已接近一半，而一年前这个数字还不到 25%。开发者可以直接下载权重、二次修改、本地部署，这在数据敏感和成本敏感的行业里是压倒性的优势。参考消息援引的报道也显示，越来越多美国 AI 从业者认为，中国的开放权重模型比闭源模型更有利于 AI 安全——这直接挑战了 Anthropic 等公司坚持的「开源有威胁」论调。

**便宜**是第二张牌。DeepSeek V4 Flash 正式版上线时，每百万 Token 输入只要 1 元左右，这个价格让海外开发者几乎没有犹豫的成本。非洲市场更是典型样本：中国模型普遍免费可下载、无需提前申请授权，阿里巴巴的多语言处理能力在非洲表现优于 Meta 和 Google，中国 AI 模型正在新兴市场建立事实标准。

**够用**是最后一环。能力差距不再构成壁垒。DeepSeek V4 Pro 的推理和代码能力已经逼近 GPT-5 系列，小米、腾讯、智谱的模型各自在 Agent、长上下文、编程场景里站稳了位置。当性能差距缩小到可以忽略，价格和开放性就决定了开发者把票投给谁。
![插图_03_三张王牌](/images/16aa6a64-dd7e-4694-95c0-3fd76d46353d.png)


## 一个反直觉的信号：开始涨价了

就在榜单刷屏的同时，一个更值得玩味的信号出现了。

8 月 13 日晚，DeepSeek 突然发布 V4 Pro 正式版，并宣布 API 全面调价，8 月 17 日起执行峰谷定价：高峰时段 V4 Pro 每百万 Token 输出从 6 元涨到 27 元，涨幅 350%；即便是闲时价格 13.5 元，也是原来的 2.25 倍。

全网把这个消息概括成一句话：告别「只收电费」的补贴时代。

这其实是霸榜故事的完整拼图。低价补贴让中国模型在一年内拿下了全球调用量的半壁江山，而现在，当用户习惯已经养成、能力已经验证，头部玩家开始把价格拉回商业化的正轨。涨价没有发生在份额不足的时候，而是发生在登顶之后——这说明国产模型的议价能力，已经比很多人以为的要强。
![插图_04_涨价转折](/images/f90915e4-748c-4b13-98f8-a7e6b6e64382.png)


## 从霸榜到商业化，竞争进入下半场

OpenRouter 的榜单变化，折射的是一场更深的格局迁移。

两年前，国产模型还在追着 GPT 的版本号跑；一年前，价格战让国产 API 便宜到「自杀式」的程度；而今天，中国模型在调用量上全面登顶，同时开始主动调整定价策略。中美大模型的价差正在收窄，竞争从「拼价格」转向「拼生态、拼工具链、拼商业化能力」。

值得一提的是，DeepSeek 在同一天还开源了 Harness（Agent 执行框架）的 v0.1 预览版，采用 MIT 协议和「一切皆插件」的设计。模型之外，中国公司正在把 Agent 底座、开源生态、定价体系一起摆上牌桌。

榜单上的名字会变，但趋势已经清晰：在真实世界的开发者用脚投票的战场里，中国模型已经从追赶者变成了定义规则的人。

这一周的数据不是终点。当开源、低价、够用三张牌打完之后，真正的考验才刚刚开始——能不能在涨价之后留住用户，能不能在 Agent 时代继续领跑，答案会在接下来几个月的榜单里逐渐浮现。
