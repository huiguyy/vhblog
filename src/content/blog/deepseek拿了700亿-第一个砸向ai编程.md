# DeepSeek拿了700亿，第一个砸向AI编程
![图片](/images/24eb3508a8e0cfa2.png)

700亿。这个数字从500亿一路涨上来的时候，我还在想是不是哪家媒体又搞错了。结果彭博社5月22日的报道确认了，DeepSeek这轮融资的谈判规模确实到了700亿元人民币，投前估值450亿美元。如果最后落地，这将是中国AI初创公司有史以来最大的一笔单轮融资。

更让我意外的是钱从哪来。创始人梁文锋个人准备出资200亿，占整轮融资的40%。一个创始人敢拿自己的真金白银砸进去，说实话，比任何PPT上的愿景都更有说服力。

但今天我最想聊的不是融资本身，而是这700亿弹药第一个砸向的战场，AI编程。

## 从500亿到700亿，口径一路狂飙

两周前外媒报出来的数字还是500亿。当时大家觉得已经很离谱了，结果现在直接跳到700亿。

这个口径变化挺有意思。第一次是3亿美元的小消息，然后变成500亿，现在到了700亿。每一次数字往上跳，都意味着有新的投资方在加入谈判。腾讯、IDG资本、砺思资本都接近确定参投，加上梁文锋自己的200亿，这个盘子越做越大。

梁文锋在至少一次投资者会议上说得很直白，公司会继续做开源AI模型，追求的是AGI，不是短期变现。这话放在别的创业者嘴里可能像是场面话，但放在一个自掏200亿的人嘴里，分量不太一样。

## Harness团队，DeepSeek版的Claude Code

5月20日，DeepSeek官网上线了两个新岗位，Agent Harness产品经理和Agent Harness研发工程师。同一天，DeepSeek资深研究员陈德里在社交媒体上证实，公司正在组建Harness团队，「简单来说就是对标Claude Code，做DeepSeek Code Harness」。
![图片](/images/43e0817400b230d8.png)
这个信息量很大。我拆开说说。

第一，为什么叫Harness？在DeepSeek的产品定义里，Model + Harness = Agent。模型是大脑，Harness是身体，是执行反馈纠错的完整闭环系统。裸模型能聊天能写代码，但加上Harness才能变成真正的编程智能体，能记住上下文，能调用工具，能跑测试，能读错误然后自己修。

第二，谁在带队？前TSY Capital联合创始人崔添翼。这个名字在量化圈很响，但更猛的是他的竞赛背景，本科期间6次拿到ACM国际大学生程序设计竞赛亚洲区金牌。他创立的TSY Capital，开发团队人均约5枚ACM级别金牌。今年3月他正式加入DeepSeek，技术和金融双重背景，既懂算法又懂产品化。

第三，团队在北京海淀区融科资讯中心，紧邻北大清华。岗位描述明确写了，入职者要深度参与「DeepSeek桌面端Agent产品」从0到1的完整开发周期。从招聘节奏看，这不是试水，是要正式下场。

## V4已经为编程智能体做了专项优化

Harness团队不是从零开始。DeepSeek在4月24日发布的V4模型，就已经为编程智能体场景做了专项优化。

两个版本，V4-Pro和V4-Flash。V4-Pro是1.6万亿参数、490亿激活，V4-Flash是2840亿参数、130亿激活。都有100万Token的上下文窗口，能一口气吃下中型项目的完整代码库。

还有个细节。DeepSeek最近灰度上线了识图模式。为什么？因为V4-Pro接入Claude Code之后，开发者在日常使用中发现，模型看不了架构图、设计稿和错误截图。这在编程智能体场景里是硬伤，你让AI帮你改bug，它连报错截图都看不懂。

识图模式就是为了补上这个缺口。从「能写代码」到「能看图理解上下文」，这一步看起来小，但对编程智能体来说是质变。
![图片](/images/5bdcdd4688ff1294.png)

## 代码可解释性，AI编程的信任阶梯

Understand-Anything这个项目也值得说。GitHub上14.7K星，1.4K Fork，能把任意代码库、知识库、文档转化为可探索、可搜索、可对话的交互式知识图谱。

它用了6个专用Agent来分析代码库，项目扫描器、文件分析器、架构分析器、导游构建器、图谱审查器、领域分析器。文件分析器支持并行处理，每批20到30个文件。生成的知识图谱保存为JSON，可以提交到代码仓库团队共享。

已适配9个平台，Claude Code、Codex、Cursor、VS Code、Gemini CLI都在列。

为什么这个项目突然爆了？因为它瞄准的是AI编程最核心的信任问题。现在的AI编程工具能写代码，但你不知道它为什么这么写。Understand-Anything做的事情是让代码变得可解释，从「能不能写」到「靠不靠谱」再到「能不能看懂」，这是AI编程的信任阶梯。
![图片](/images/969fcc08432dfb48.png)
## 700亿的赌注

回到融资。这700亿的意义不只是钱多。

中国AI圈一直有个尴尬，模型能力追上来了，但产品化差一截。DeepSeek V4在编码能力上已经超越了同期的Claude和部分GPT版本，API价格还只有对方的零头。但模型强不等于产品强，Claude Code能占54%的模型份额靠的不是Opus本身，而是整套Harness架构。

DeepSeek现在要做的事，就是把V4的模型优势转化为编程智能体的产品优势。700亿是弹药，Harness团队是枪，崔添翼是扣扳机的人。

说真的，我觉得这个时机选得不错。Claude Code太受欢迎反而被微软砍了，6月30日前Experiences和Devices团队必须转Copilot CLI。Cursor忙着应对500亿估值的压力，SpaceX 600亿收购选择权的消息满天飞。OpenAI内部还在重组，Brockman刚夺完权。

编程智能体市场现在是个真空期，谁先冲出来谁就占位。

梁文锋说AGI大于赚钱。这话听上去像理想主义，但700亿真金白银砸下去的第一个目标偏偏是最赚钱的编程赛道，这个组合本身就很DeepSeek，一边说着不商业化，一边把最商业化的产品先做出来。

我有时候觉得，这才是真正懂怎么花钱的人。不是拿钱去追热点，是拿钱去卡位。编程智能体是AI产品化的第一块多米诺骨牌，推倒它，后面的才会跟着倒。
![图片](/images/fe0b31968d1ac752.png)
至于DeepSeek Code Harness最后能不能打，还得看产品。但至少，方向是对的，钱是够的，人是对标Claude Code找的。这个仗，有得打。
