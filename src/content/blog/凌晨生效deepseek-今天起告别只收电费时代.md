# 凌晨生效！DeepSeek 今天起告别"只收电费"时代
![封面_告别只收电费时代](/images/c72f769e-a532-4348-8144-481f93203a5c.png)


## 从 6 元到 27 元，一个时代结束了

2026 年 8 月 17 日 0 时，DeepSeek API 峰谷定价正式生效。

这不是一次普通调价。旗舰模型 V4-Pro 高峰时段每百万 tokens 输出价格从 6 元直接跳到 27 元，涨幅 350%。部分规格最高涨幅 1100%。闲时半价 13.5 元，也没回到原来的 6 元。

换句话说，即便是"打折"时段，也比以前贵了一倍多。

过去半年，DeepSeek 用"只收电费"的极低价格撕开了全球大模型市场，把 OpenAI 和 Anthropic 的 API 价格拽下来一个数量级。现在，价格屠夫决定不再做慈善了。


## 峰谷定价：不是涨价，是"错峰"

DeepSeek 给出的定价逻辑不算复杂：把一天切成两段。

高峰时段：北京时间 9:00-12:00、14:00-18:00。其余时间全是闲时。

高峰价格是闲时的两倍。官方说法叫"为了更加合理地调配资源"，鼓励开发者把批量任务挪到夜间跑。

这在大模型行业里并不常见。云计算厂商搞峰谷电价好多年了，但 API 定价按时段分级，DeepSeek 是国内第一家做这么硬的。

背后的信号很明确：算力不够用了。过去半年 DeepSeek 的调用量一直在暴涨——OpenRouter 周榜上，DeepSeek-V4-Flash 以 8.83 万亿 tokens、570% 的增速连续霸榜。用户量上来了，GPU 就那么多，白天高峰期挤兑是必然的。

峰谷定价本质上是给算力"削峰填谷"——用价格杠杆把非紧急任务推到晚上，白天把算力留给真正需要实时响应的用户。
![插图_01_峰谷定价](/images/1fd000b9-0cf3-4066-8ca8-2a31d5a133d9.png)

## 涨价不影响免费用户，但 API 开发者要算账了

一个关键信息：这次调价只针对 API 付费调用，普通用户在 DeepSeek 官方 App 和网页端的免费使用完全不受影响。

真正被影响的，是那些靠 DeepSeek API 搭产品的开发者和企业。过去半年，一大批 AI 应用靠着 DeepSeek 的低价 API 活了下来——客服机器人、文档摘要、代码助手、智能体工作流，底座全是 DeepSeek。6 元的输出价格让初创公司能跑出体面的毛利。

现在 27 元了。成本结构瞬间变了。

一些开发者已经在算账：如果把所有调用挪到闲时，成本还能接受（13.5 元，比原来贵 2.25 倍）；但实时性要求高的场景——客服聊天、在线翻译、实时搜索——没法错峰，只能硬扛 27 元。

有人会转用 V4-Flash（更便宜的轻量版），有人会评估 Qwen3.8 或 GLM-5.3 的 API 价格，也有人干脆咬牙扛下来。但无论如何，"蹭便宜 API"的窗口期结束了。
![插图_02_算力水坝](/images/3c01c9f9-e6ba-4faf-9bc4-e1657498c233.png)


## 从"价格战"到"回血战"

DeepSeek 涨价的时间点很微妙。

8 月 13 日发布 V4-Pro 正式版，同日宣布调价，4 天后生效。节奏干脆利落，没有给市场留太多缓冲期。

同期，DeepSeek 的融资进展也在加速：首轮融资 500 亿元落地（腾讯 100 亿、宁德时代 50 亿、网易京东各 30 亿，创始人梁文锋个人出资 200 亿），投后估值约 4000 亿元。7 月传出筹备科创板上市，目标 2027 年挂牌。

这个拼图拼起来很清晰：DeepSeek 不再是那个"不差钱、只管烧"的极客团队了。它要商业化、要回血、要给投资人一个能讲通的财务故事。

据 The Information 报道，DeepSeek 年化收入约 4-5 亿美元，V4 API 毛利率超过 50%。涨价之后，毛利率只会更高。从"价格屠夫"变成"价格标杆"，DeepSeek 正在做一件中国 AI 公司很少做的事——用定价权定义自己在行业里的位置。
![插图_03_开发者算账](/images/6677f30e-62dd-4bae-b21b-286933d64608.png)


## 中国大模型的定价权时刻

更大的意义在行业层面。

过去两年，中国大模型的价格战打到底裤都没了。各家争着降价、争着免费，生篇文章就喊"颠覆 OpenAI"。结果是用户爽了，但模型公司集体失血。

DeepSeek 这次涨价，相当于在行业里插了一个锚点：好模型就是该卖这个价。

这个动作给了其他中国模型公司喘息空间。如果 DeepSeek——全球下载量第一的开源模型——都能涨价 350%，别的公司就不用再硬扛价格战了。GLM-5.3、Qwen3.8、Kimi K3 的定价策略大概率会跟进调整。

一句话：中国大模型行业的"赔本赚吆喝"时代，可能真的要结束了。

对开发者来说这不一定是坏事。价格回归正常，意味着行业从"卷低价"转向"卷能力"——谁的后训练更强、谁的编程跑分更高、谁的上下文更长、谁的生态更完善，才真正决定用户用谁。这比"谁更便宜"健康得多。

8 月 17 日 0 时，DeepSeek API 价格跳表的那一刻，可能被一些人记住——中国大模型从"电费时代"走进了"定价权时代"。
