# 阿里双响，腾讯督战，飞书 ARR 翻倍：办公场景成 AI 大厂新战场
![封面_三强大战办公场景](/images/90fb9c70-609d-46f7-9496-a7f2e706ecee.png)


8月3日，三个消息在同一天砸下来。

**阿里巴巴** 正式发布 Qwen3.8-Max（2.4万亿参数，下周开源）并同步推出企业级 Agent 产品「千问办公」（QwenWork）开启公测，整合了 QoderWork、MuleRun、悟空三款产品。公测第一天，新用户注册送2000积分。

**腾讯** 内部将 WorkBuddy 定义为「超级项目」，董事长马化腾亲自督战，全面打通企业微信、QQ、飞书、钉钉，可跨平台远程调度。

**飞书** 的 aily ARR 超30亿元，2026年二季度同比增长超过100%。新增客户里，超过九成同步采购飞书 AI 产品。

同一天，三家全亮牌。办公场景，成了AI大厂的新战场。

* * *

## 阿里双响：模型 + 产品，一天全上

8月3日对阿里来说不是普通的一天。

Qwen3.8-Max 是千问家族迄今规模最大的模型，总参数量第一次推到2.4万亿，单次推理激活参数95B。编程、真实办公场景、长程任务、多模态分析，综合表现进入全球第一梯队。

更关键的是，下周将开源 Qwen3.8-Max 权重，同步开源 Qwen3.8-27B。

同一天，千问办公（QwenWork）公测。这是阿里旗下企业级 Agent 产品的正式亮相，由 QoderWork、MuleRun、悟空三款产品全面整合而来，号称业内首款同时支持桌面端 Agent、云端 Agent、企业协同 Agent 的产品。

千问办公和钉钉深度打通，可在授权范围内调取钉钉群聊记录、会议文档、日程审批、内部知识库等组织数据。公测当天，钉钉 PC 端和手机端内置入口同步预告上线。

一句话，**阿里在用钉钉的渠道，推千问的产品**。
![插图_01_阿里双响双星齐发](/images/169d6ac3-0a77-459f-b4cc-5d2c4230a7d0.png)

* * *

## 钉钉：成了阿里的「内部竞争战场」

这个逻辑很有意思。

钉钉是阿里旗下月活数一几亿的办公平台。千问办公需要钉钉的渠道和生态来获客。但钉钉本身也有自己的 AI 能力。

千问办公深度打通钉钉，钉钉内置千问的 Agent。这不是合作，是**用左手给右手导流**。

但问题来了——如果钉钉的用户最终被千问办公截走，钉钉的价值在哪里？

阿里云和钉钉之间，有一条没有说出口的裂缝。这条裂缝在8月3日被一张「深度打通」的新闻稿暂时遮住，但迟早要正面回答。

**钉钉成了阿里的内部竞争战场，而不是对外的护城河。**
![插图_02_钉钉内部战场](/images/90b056eb-935b-44dc-85d6-5a49d72f22ec.png)


* * *

## 腾讯 WorkBuddy：马化腾亲自督战的「超级项目」

腾讯的打法不一样。

WorkBuddy 最早脱胎于腾讯的 AI 编程助手 CodeBuddy，定位是「面向普通办公人群的 AI 原生工作台」。3月9日正式上线，经过内部2000余名员工和上万外部用户真实工作验证。

腾讯没有在同一天搞两场发布会，而是把 WorkBuddy 定义为「超级项目」，马化腾亲自督战。

这句话的信息量很大。腾讯这么大，超级项目不多，能让马化腾盯着的，意味着资源无上限、优先级最高。

WorkBuddy 的差异化是「全协同」——无缝对接企业微信、微信、飞书、钉钉等主流办公 IM，支持跨平台远程遥控。通勤路上发一条指令，到工位时报表已经生成好了。

它兼容 OpenClaw 技能生态，内置20多个办公技能包。用户不用换工具，WorkBuddy 去调度这些工具完成任务。

**腾讯的打法是：不做模型，做模型之上的调度层。用协作生态换用户黏性。**
![插图_03_马化腾督战超级项目](/images/2be8a8a5-68c8-4298-a3d3-ed2057b5e242.png)

## 飞书 aily：ARR 增 100%，九成新增客户买 AI

飞书没有在8月3日搞发布会，但它手里有最硬的数据。

**2025年，飞书 ARR 超30亿元。2026年二季度 ARR 同比增长超过100%。**

新增客户里，超过九成同步采购飞书 AI 产品。这意味着飞书的 AI 能力不再是单独卖的功能，而是成了签单的必要条件。

飞书 aily 是原生的 Agent 办公平台，同时覆盖三个产品形态：个人轻量化助手（aily 智能伙伴）、专业版席位服务、企业自研智能体开发平台（aily 开发平台）。开箱即用的智能伙伴直接在飞书聊天、文档、多维表格里调用，不需要安装独立客户端。

横评数据显示，aily 在飞书生态联动、团队内容创作两大核心办公场景得分领先。开放的多 Agent 协同链路，可以把 Codex、Claude Code 生成的代码方案自动同步到飞书群和项目文档，完成跨团队评审闭环。

飞书没有在8月3日抢头条，但它可能是这场仗里最不慌的那一个。
![插图_04_飞书ARR翻倍飞轮](/images/9d7b3333-62f4-466e-a7aa-e4306b7fd034.png)

## 三种逻辑，一场仗

**阿里** 的逻辑是：模型能力 → 产品落地。从 Qwen3.8-Max 到千问办公，用模型层的优势往下打产品层，下周还开源 Max 权重，用开源社区补生态。

**腾讯** 的逻辑是：协作生态 → 模型调度。WorkBuddy 不自研基座模型，用接入的方式把各个模型的能力组装成协作场景，马化腾亲自督战意味着这是战略级入口。

**飞书** 的逻辑是：场景沉淀 → 数据护城河。飞书的核心价值不是模型多强，而是用户在飞书里产生的协作数据。aily 能读取这些上下文，独立完成调研分析、批量文案、项目跟进、会议纪要。AI 产出直接沉淀为可协作的飞书文档，形成飞书自己的数据飞轮。

三条路，没有对错，但结果会决定谁吃这块蛋糕。
![插图_04_飞书ARR翻倍飞轮](/images/9929e591-806c-4e5b-a43c-3bcf154b8064.png)

## 办公 Agent 这场仗，才刚开局

8月3日是一个节点，但不是终点。

Qwen3.8-Max 下周开源，WorkBuddy 正在加速迭代，aily 的数据飞轮才刚转起来。

对普通用户来说，好消息是竞争会压低价格。千问办公公测第一天，新用户送2000积分，第一周每天登录再领500到2000积分。

对中大企业来说，问题是选谁。阿里模型强但产品新，腾讯协作强但模型依赖第三方，飞书场景深但切换成本高。

这场仗，最后比的不是谁的技术最强，而是**谁能让用户在它的工作流里待得最久**。

得留存量者得天下。
